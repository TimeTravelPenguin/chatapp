# Chatapp

This repo contains a mock chat application using the Iced crate in Rust.

The purpose of this project is to renew and refresh my knowledge of:

- Databases: using an ORM with a code-first approach,
- Client/Servers: using TLS to connect clients to a server with appropriate communication
  protocols,
- Data privacy: allow communication to be encrypted,
- GUI: learn to make application in Rust with a user interface.

While I have done these tasks in the past, they were done individually and in isolation.
Although this application is nothing overly advanced, it is my attempt to push myself to
learn new things.

## Building / Running

To use this app, you must clone the repo and use `cargo` to compile the project.

Once `cargo build` completes, `cargo run -- --help` will show you the
available commands. The main features exist with the `cargo run client` and `cargo run
server` commands.
